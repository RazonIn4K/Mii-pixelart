## Live AI finding

The authorized live provider check proved the staging integration can return
advice. A subsequent Create request using the selected free Gemma model
returned descriptive prose plus a syntactically valid but entirely empty grid.
The strict server validator correctly rejected it as non-applyable; the canvas
was not changed.

Investigation found that switching from Advice to Create retained the local
transcript and the server forwarded stale advice prose under the structured
sketch prompt. The deployed source already attempted one bounded repair, but
provider variability plus the mixed-mode history still produced no painted
cell. This is a reliability defect rather than a validator defect; the empty
grid must never be accepted or synthesized from prose.

The live requests consumed only the approved provider and rate-limit budget and
updated browser-local AI history. They did not change a project, profile, role,
OAuth setting, D1 project record, or R2 object.
